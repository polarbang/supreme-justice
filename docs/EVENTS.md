# 이벤트 표

> 이 문서는 `npm run docs:events`로 코드(`src/game/surpriseEvents.ts`, `src/game/weekendActivities.ts`)에서 자동으로 만든다. 직접 고치지 말고 코드를 고친 뒤 다시 실행할 것.

## 1. 기습 이벤트

### 규칙

| 항목 | 값 |
|---|---|
| 횟수 | 사건 3건(한 바퀴) 동안 최대 1회. 바퀴마다 60% 확률로, 3건 중 무작위 차례에 뜸 (첫 바퀴는 두 번째 사건부터) |
| 시점 | 그날 아침 집무실에서, 사건 배당 전에 뜬다. 답하기 전에는 사건을 배당받을 수 없다 |
| 선택 | 이벤트 하나에 **참여한다 / 거절한다** 중 하나 |
| 일반 이벤트 참여 | 주 능력치 +6, 다른 능력치 −3 |
| 거절 | 변화 없음, 또는 능력치 하나 −3 (윗사람 부탁·공식 요구 등) |
| 유혹 이벤트 참여 | 주 능력치 +8, 평판 −6. 25% 확률로 바로 알려져 평판 −6 추가 |
| 유혹 이벤트 비중 | 그날 뽑히는 이벤트의 약 25% |
| 반복 방지 | 같은 이벤트는 사건 12건(4바퀴) 안에 다시 나오지 않음. 정치권 제안(정당의 총선 영입 제안, 정치권 실세와의 비공개 회동, 정부 고위직 입각 타진)은 한 판에 한 번씩만 |
| 건강 40 미만 | 참여 시 건강이 깎이는 이벤트는 나오지 않음 |
